# Decision records

Short notes on choices that are hard to reverse. One file per decision,
numbered in order, never edited after it is accepted: a later decision that
changes an earlier one gets its own file and says which it replaces.

Each record has four parts: the context, the decision, what else was
considered, and the consequences.
